
# Lab 04 - SQL Queries and Aggregation

## Overview

This laboratory assignment focuses on SQL querying, data filtering, aggregation, and data manipulation using the BikeStores sample database.

The assignment consists of 15 SQL exercises involving customer, product, order, and inventory data.

## Database: BikeStores

The database includes two main schemas:

- **Sales:** Customers, orders, order items, stores, and staff
- **Production:** Products, brands, categories, and stocks

## Concepts Covered

- SELECT and WHERE
- LIKE and SQL wildcards
- IN, NOT IN, and BETWEEN
- TOP and ORDER BY
- Column and table aliases
- Aggregate functions: COUNT, SUM, AVG, MIN, MAX
- DISTINCT and COUNT(DISTINCT)
- Multi-table queries
- INSERT INTO
- UPDATE and DELETE

## Laboratory Tasks

1. Filter customers using pattern matching
2. Filter products by category and price range
3. Query customers using NOT IN and NOT LIKE
4. Apply character-range wildcard filtering
5. Retrieve the five most expensive products
6. Calculate customer statistics
7. Analyze orders within a date range
8. Query products across multiple tables
9. Calculate order counts and net revenue
10. Count distinct customers purchasing specific products
11. Retrieve the highest-value order items
12. Compare product prices against their average
13. Insert multiple order items
14. Update product prices conditionally
15. Delete inventory records based on conditions
