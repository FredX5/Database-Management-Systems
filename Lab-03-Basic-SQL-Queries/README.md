
# Lab 03 - Basic SQL Queries

## Overview

This laboratory assignment focuses on writing basic SQL queries using the BikeStores sample database.

The objective is to retrieve, filter, insert, update, and delete data using SQL statements.

## Database: BikeStores

BikeStores represents a bicycle retail chain with multiple stores.

The database contains two main schemas:

- **Sales:** Customers, orders, order items, stores, and staff
- **Production:** Products, brands, categories, and stocks

## Concepts Covered

- SELECT and SELECT DISTINCT
- WHERE conditions
- AND, OR, and NOT operators
- NULL value handling
- Queries involving multiple tables
- INSERT INTO statements
- UPDATE statements
- DELETE statements
- Data verification using SELECT queries

## Laboratory Tasks

The assignment consists of 10 SQL exercises:

1. Retrieve unique discount values
2. Filter products using multiple conditions
3. Find customers with missing phone numbers
4. Retrieve products based on brand and year
5. Find customer cities for rejected orders
6. Insert a new customer
7. Insert a new order
8. Update product prices
9. Update order information
10. Delete products matching specific conditions
